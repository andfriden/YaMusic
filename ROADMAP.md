# YaMusic Roadmap

Актуальный план развития проекта. Состояние на **октябрь 2026**: выпущены **v0.13.0**, **v0.14.0** и **v0.14.1**.

Раздел «Аудиокниги» реализован в отдельной ветке `feat/audiobooks` и в `main` пока не входит.

---

## Выпущено

### v0.14.1 — Дизлайки, станции и автообновление

- [x] Дизлайки треков: кнопка в списках и плеере, событие ротора, взаимоисключение с лайком
- [x] Список станций из `/rotor/stations/dashboard` — личные станции и персональная волна (откатано: дашборд отдавал не все станции, вернулись на `/rotor/stations/list`)
- [x] «Моя волна»: без повторов недавно сыгранного, лимит очереди, замена очереди на пропуске и дизлайке
- [x] Автообновление: проверка релизов GitHub, установка DMG на macOS, «пропустить версию»

### v0.14.0 — Playback Quality, Lyrics & Home

#### Качество звука

- [x] Выбор качества аудио: низкое / среднее / высокое / lossless (сохраняется в QSettings)
- [x] Показ кодека и битрейта текущего стрима — через `download-info` вместо сломанного `get-file-info`
- [x] Переработанный попап настроек: выбор качества и понятная раскладка

#### Тексты песен

- [x] Синхронизированный текст через `/tracks/{id}/lyrics?format=LRC` (подписанный запрос)
- [x] Фолбэк на публичную базу LRCLIB по названию и исполнителю
- [x] Подсветка текущей строки в реальном времени и автопрокрутка

#### Контент

- [x] Треки без цензуры: подмена на неcensored-версии по открытой базе FckCensorData
- [x] Блок «Колесо» на главной странице (`POST /wheel/new`)
- [x] Доступность дорожек: разбор флага `available`, роль `available` в `AlbumModel`

#### Исправления

- [x] Недоступные дорожки больше не запрашиваются у сервера: вместо `403 no-rights` — понятное сообщение, приглушение и кнопка перехода во внешний сервис (`actionButton`)
- [x] Позиция плеера больше не «залипает» на ~20 секундах при буферизации
- [x] История: разбор всех вариантов ответа `/music-history` и выравнивание полезной нагрузки `/play-audio`

### v0.13.0 — Catalog & Library Expansion

#### Genre Radio Stations

- [x] Ротор/dashboard для жанров: получение станций через API ротора
- [x] UI для станций (запуск, управление)

#### Раздел «Станции» и радио исполнителя

- [x] Полный список станций ротора (`/rotor/stations/list`), группировка по типам
- [x] Воспроизведение через сессионный ротор: `POST /rotor/session/new`, `/rotor/session/<id>/tracks`
- [x] Фидбек ротора (`trackStarted` / `trackFinished` / `skip`) для активной сессии
- [x] Автоподгрузка следующей партии при исчерпании очереди станции
- [x] Кнопка «Слушать» на странице исполнителя: все треки артиста, затем цепочка похожих без повторов
- [x] Продолжение прослушивания альбома через радио артиста (источник очереди `artistRadio`)

#### Playlist Management

- [x] Создание пустого плейлиста (POST /users/{uid}/playlists/create)
- [x] Удаление плейлиста (POST /users/{uid}/playlists/{kind}/delete)
- [x] Переименование плейлиста (POST /users/{uid}/playlists/{kind}/name)
- [x] Добавление треков в плейлист (POST /users/{uid}/playlists/{kind}/change, diff с op `insert`)
- [x] Удаление треков из плейлиста (POST /users/{uid}/playlists/{kind}/change, diff с op `delete`)
- [x] UI: контекстное меню «Добавить в плейлист» на треке
- [x] UI: кнопка удаления трека при просмотре плейлиста
- [x] UI: кнопка «Добавить в плейлист» на треках в альбоме, исполнителе и плейлисте

#### Album/Artist Likes — Write

- [x] Кнопка лайка альбома на AlbumPage (POST /users/{uid}/likes/albums/add-multiple)
- [x] Кнопка лайка исполнителя на ArtistPage (POST /users/{uid}/likes/artists/add-multiple)
- [x] Обновление состояния likedAlbumsModel / likedArtistsModel после операции

#### Подкасты

- [x] Парсинг блоков подкастов из лендинга (`/landing3?blocks=...,podcasts`)
- [x] Раздел «Подкасты» — страница с сеткой карточек
- [ ] Воспроизведение подкастов (карточки пока не открываются)

#### Скачивание

- [x] Скачивание трека в «Загрузки» с метаданными (TagLib) и вложенной обложкой
- [x] Кнопка ↓ в Now Playing Bar и развёрнутом плеере
- [x] `TrackService::loadDownloadUrl` — прямой URL скачивания по кодуку

#### Стабильность и техдолг

- [x] Стабилизирован StreamProxy для живого аудио (стрим больше не обрывается)
- [x] Нормализованы иконки станций, исправлено закрепление названия на карточке
- [x] Кнопка play в развёрнутом плеере обёрнута в Item — контролы не перекрываются
- [x] TagLib добавлена в CI на все платформы; исправлен поиск библиотеки на Windows (vcpkg)
