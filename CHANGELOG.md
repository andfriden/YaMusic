# Changelog

Все заметные изменения проекта YaMusic.

---

## [v0.14.2] — 2026-10-16

### Возможности

- Бейджи контента у треков: «AI» (контент сгенерирован ИИ — по открытой базе ИИ-артистов Slopless) и «Без цензуры» (у трека есть нецензурная версия из FckCensorData). Показываются в строке трека, в панели воспроизведения и в развёрнутом плеере
- Перекрёстное затухание работает и для нескачанных треков: поток следующего трека запрашивается с запасом на сеть, затухание начинается по готовому потоку — переход не открывается тишиной
- Отчёты о падениях: сигналы, `terminate` и `qFatal` пишут отчёт в файл с шапкой окружения, хвостом журнала Qt и стеком вызовов; после падения окно само предлагает посмотреть отчёт, скопировать его и отправить в трекер проекта, а пункт «Отчёты о падениях» в настройках открывает их в любой момент

### Исправления

- Раздел «Станции» снова берёт список из `/rotor/stations/list`: в ответе `/rotor/stations/dashboard` приходила лишь часть станций. Откат изменения из 0.14.1 — личные станции и персональная волна в списке снова не показываются

### Техническое

- `src/Yandex/Catalog/AiService` — загрузка и кэширование на сутки списка ИИ-артистов из базы Slopless
- Признаки бейджей не лежат в моделях: QML спрашивает их у контроллера по `artistId`/`trackId` и пересчитывает привязки по счётчикам ревизий `aiRevision`/`censorRevision`
- QML-компонент `Badge` — маленькая пилюля для пометок трека

## [v0.14.1] — 2026-10-15

### Возможности

- Дизлайки треков: перечёркнутое сердце в строке трека и в панели воспроизведения, событие `dislike` уходит в ротор станции и волны; лайк и дизлайк взаимоисключающие
- Автообновление: проверка релизов на GitHub, тихая проверка при запуске, «пропустить версию», скачивание и установка обновления на macOS с перезапуском
- Раздел «Станции» берёт список из `/rotor/stations/dashboard` — появились личные станции и персональная волна (с откатом на прежний список)

### Исправления

- «Моя волна» больше не возвращает недавно сыгранное, очередь ограничена 100 треками
- Пропуск и дизлайк пересобирают очередь волны: оставшееся отбрасывается, играет свежая партия ротора

### Техническое

- `LikesService` — список дизлайков и операции добавления/снятия, состояние кнопок в QML по счётчику изменений
- `src/Update/` — `UpdateChecker` (список релизов, сравнение версий, выбор файла под систему) и `UpdateInstaller` (DMG, монтирование, подмена бандла скриптом-помощником после выхода)
- Версия приложения приходит из CMake через `YAMUSIC_VERSION` и сравнивается с тегами релизов
- `.clang-format` под стиль проекта: 2 пробела, 100 колонок, указатели вправо

## [v0.14.0] — 2026-10-13

### Возможности

- Выбор качества аудио — низкое / среднее / высокое / lossless (сохраняется в QSettings)
- Показ кодека и битрейта текущего стрима в плеере
- Переработанный попап настроек: выбор качества и понятная раскладка
- Синхронизированный текст песни через `/tracks/{id}/lyrics?format=LRC` с фолбэком на публичную базу LRCLIB
- Треки без цензуры: подмена на версии без цензуры по открытой базе FckCensorData
- Блок «Колесо» на главной странице (`POST /wheel/new`)

### Исправления

- Дорожки без прав больше не запрашиваются у сервера: вместо `403 no-rights` — понятное сообщение, приглушение в списке и кнопка перехода во внешний сервис (`actionButton`)
- Позиция плеера больше не «залипает» на ~20 секундах при буферизации
- История: разбор всех вариантов ответа `/music-history` и выравнивание полезной нагрузки `/play-audio`

### Техническое

- `Track.available` и роль `available` в `AlbumModel` — признак прав на воспроизведение через Music API
- `AlbumService` разбирает `type` и `actionButton` альбома
- Кодек и битрейт берутся из `download-info` — сломанный `/get-file-info` убран

## [v0.13.0] — 2026-10-08

Бета-сборка для macOS (Intel и Apple Silicon), Linux и Windows.

### Возможности

- Новый раздел «Подкасты» — страница с карточками-сеткой на основе лендинга
- Скачивание треков в «Загрузки» — сохранение с метаданными (теги) и встроенной обложкой (кнопка ↓ в Now Playing Bar и развёрнутом плеере)
- Улучшение UI плеера — глубина, свечение и градиентные акценты в развёрнутом плеере и Now Playing Bar
- Встраивание обложки прямо в сохранённый файл трека

### Исправления

- Стабилизирована потоковая передача: StreamProxy для живого аудио перестал обрываться
- Нормализованы иконки станций и исправлено закрепление названия на карточке станции
- Кнопка play в развёрнутом плеере обёрнута в Item — контролы не перекрываются

### Техническое

- `DownloadService` — загрузка аудио, обложки и запись метаданных, сохранение в системную «Загрузки»
- TagLib добавлена в CI на все платформы; исправлен поиск библиотеки на Windows (vcpkg)

## [v0.11.0] — 2026-09-20

Бета-сборка для macOS (Intel и Apple Silicon), Linux и Windows.

### Возможности

- Полноценный поиск: вкладки «Треки | Альбомы | Исполнители | Плейлисты» и навигация по результатам
- Вкладка «Похожие» в Expanded Now Playing
- Автопереход на похожий контент при завершении очереди
- Копирование трека «Артист — Трек» через контекстное меню во всех списках
- Воспроизведение напрямую из стрима; offline-режим и кэш стримов убраны
- Стабильный стриминг через StreamProxy QIODevice
- Отправка факта прослушивания через `/play-audio`
- «Недавно прослушаны» читаются через `/music-history`
- Релизные пакеты: AppImage build script и NSIS-установщик (позже заменён на portable-архив)

### Исправления

- Устранены QML-варнинги
- «Моя волна»: непрерывное воспроизведение через догрузку батчей
- Нормализация стиля кода по проекту (форматирование, `Q_ASSERT` в конструкторах, убраны QString-обёртки)
- AppImage/CI: починка сборки пакетов (linuxdeploy-plugin-qt, PATH, извлечение VERSION)

### Техническое

- Рефакторинг: извлечены контроллеры Lyrics/Theme/Accent
- README: компактнее, унифицированы имена релизных пакетов
- Windows: отказ от NSIS-установщика — оставлен только portable-архив
