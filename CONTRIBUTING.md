# Участие в разработке

Спасибо за интерес к YaMusic. Проект небольшой, поэтому заметную доработку лучше сначала обсудить в issue — так не придётся переделывать.

## С чего начать

1. Посмотрите [ROADMAP.md](ROADMAP.md) — возможно, идея уже в плане
2. Для багов — [баг-репорт](.github/ISSUE_TEMPLATE/bug_report.yml), для идей — [feature request](.github/ISSUE_TEMPLATE/feature_request.yml)
3. Уязвимости — по [SECURITY.md](SECURITY.md), не через публичный issue

## Сборка

Инструкции по зависимостям и сборке — в разделе [«Сборка из исходников»](README.md#сборка-из-исходников). Коротко:

```bash
git clone https://github.com/andfriden/YaMusic.git
cd YaMusic
cmake -S . -B build
cmake --build build --parallel
```

Нужны Qt 6.9 и TagLib — `CMakeLists.txt` остаётся источником истины по зависимостям.

## Стиль кода

- C++20, форматирование — `.clang-format` в корне: `clang-format -i <files>`
- Слой QML отвечает за интерфейс и навигацию, C++ — за API, модели, воспроизведение и состояние; бизнес-логику в QML не добавляем
- Новые контроллеры встраиваются по существующей схеме `QML → Controllers → Services / Models`
- Строки интерфейса — на русском, в тон существующим формулировкам

## Pull request

- Одна логичная правка на PR, без посторонних переформатирований
- Опишите, что и зачем меняется, и как проверили
- Для пользовательских изменений — черновик записи в `CHANGELOG.md`
- В коде и скриншотах не должно быть токенов, ссылок авторизации и персональных данных

## Лицензия

Отправляя изменения, вы соглашаетесь, что они распространяются под GPL-3.0, как и проект.
